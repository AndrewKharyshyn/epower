# M561 spec Rev 1 (2026-11-02, before any code): power-duration profile, uninterrupted-direction variant (follow-up to M552, audit 2026-10-29 N02)

Status: PRE-REGISTERED DRAFT for Director review. Nothing implemented. Tier C (method addition, new payload block). Branch base: `main` at M560 (`bbcd4f6`). Parent: `analyses/M552_spec.md` (Rev 1-2) and `tools/power_duration.py`; every definition there (substrate, pair stream, 5 s gap rule, strata, bootstrap, exposure sensitivity, KA conventions) is reused unchanged unless stated here.

## 1. Question and non-question
M552 reports the extreme of the NET mean power over a window; a long window can contain a reversal, so a 120 s "discharge" value can be an average of a high-discharge part and a charge part. M561 asks: what is the highest mean power the logger observed over a window of length W during which the power did NOT change direction (discharge: P >= 0 on the whole window; charge: P <= 0 on the whole window)? It is an OBSERVED extremum of a reconstructed I x V product over a one-direction window. It is not a rating, capability, limit or operating percentile, and it is not a replacement of the M552 values: both are shown, the difference (M552 net minus M561 uninterrupted) is what a reversal removes.

## 2. Definition (exact, continuous start)
Inside one supported segment (M552 gap rule) the power is piecewise linear. Insert a knot with P = 0 at every interior zero crossing (strict sign change between adjacent knots; a knot with P = 0 does not split). A DISCHARGE RUN is a maximal interval on which P >= 0; a CHARGE RUN is a maximal interval on which P <= 0 (closed: a window touching P = 0 at an end is uninterrupted). A window [s, s + W] is uninterrupted-discharge iff it lies inside one discharge run. The M561 discharge extreme of a drive = the maximum over all discharge runs of length >= W of the exact continuous-start maximum of the window mean inside that run (M552 `window_extremes` applied to the run, including the inserted zero knots; the 1 s start grid anchored at the run start is the lower bracket, the 0.5 s shift the sensitivity). Charge: the same on -P, reported as a magnitude. A drive with no run of length >= W reports 0 for that direction and is counted (as in M552 R5), with a separate count of drives with no eligible run.
By construction, per drive, W and direction: M561 <= M552 (a window inside a run is a window of the segment); equality when the M552 argmax window is itself uninterrupted.

## 3. Estimands and reporting
Per stratum (cadence regime, never pooled, no contrast): pooled percentiles of the per-drive extremes (p50, p90, p95, p99, max) with the M552 interval rules (R4), and per W and direction: the number of drives with an eligible run, the share of drives whose M552 argmax window is uninterrupted, and the median and p95 of (M552 - M561) per drive in kW. Run-length distribution per stratum (median, p95 of eligible run seconds) so the user can see how much of the 120 s window set exists at all. Exposure-standardised and >= 600 s / >= 1800 s sensitivities as in M552.

## 4. Known answers (pre-registered)
- KB1 (constant power): M561 = M552 = P0 for every W.
- KB2 (sign flip): P = +10 for 60 s then -10 for 60 s; W = 30: discharge extreme 10, charge extreme 10 (M552 net also 10); W = 120: M561 discharge = charge = 0 with the drive counted as having no eligible run (60 s runs < 120 s), while M552 net = 0. Linear crossing (P from +10 to -10 over 20 s): the inserted zero knot sits at 10 s, runs are cut there.
- KB3 (reversal inside a window): P = +20 for 10 s, -10 for 5 s, +20 for 10 s, W = 25: M552 discharge extreme = (200 - 50 + 200) / 25 = 14; M561 discharge: no run of 25 s, so 0 for W = 25; for W = 10 it is 20.
- KB4 (zero touch): P = 10, 0, 10 (knot at exactly zero) is not split; P = 10, -1e-9, 10 is split at two crossing knots (tolerance behaviour pinned).
- KB5 (hard gates on real drives): per drive, W, direction: M561 <= M552 + 1e-9 kW (both exact, grid, shift); monotone non-increasing in W over runs eligible for both (integer multiple pairs only, as M552 R3); KA4 peak bound; KA5 closure of M552 unchanged.
- Expectation, not a gate: the gap M552 - M561 grows with W; the 5 s row differs little.

Where this section and sections 1-7 differ, this section governs.
- R1 (grid gate). The M561 start grid is anchored at the run start (the interpolated crossing or the segment start), so it is NOT a subset of the M552 grid. KB5 gates exact561 <= exact552, grid561 <= exact561 and grid561 <= exact552 (each + 1e-9 kW); no grid561 <= grid552 gate. Runs with an exact value but no grid start are counted.
- R2 (pinned knots). KB2: P = +10 on [0, 60], a zero-duration step (duplicate timestamp at t = 60) to -10, -10 on [60, 120]; the segment is exactly 120 s, so M552 at W = 120 exists and equals 0, M561 at W = 120 has no eligible run (60 s runs) and is counted as such. KB3: P = +20 on [0, 10], duplicate-timestamp step to -10 on [10, 15], step to +20 on [15, 25]; segment exactly 25 s: M552 at W = 25 = 350 / 25 = 14; M561 at W = 10 = 20, at W = 25 no eligible run. The linear-crossing case (P from +10 at t = 0 to -10 at t = 20) puts the zero knot at 10 s; on a zero-duration step the crossing knot goes at that timestamp.
- R3 (boundary rule). A knot with P = 0 whose neighbours have opposite signs (10, 0, -10) is a run boundary although nothing is inserted; a knot with P = 0 between same-sign neighbours does not split (KB4). KB4b pins (10, 0, -10). -0.0 is treated as 0. Runs of opposite direction can overlap on a P = 0 stretch; closed runs are kept.
- R4 (population). A drive whose segments are all shorter than W is absent (as in M552). 0 is reported only for a drive with a segment >= W but no run >= W. PRIMARY percentile base: conditional on an eligible run, with the eligible share (drives with run / drives with a segment >= W) beside it; the zero-included version is secondary. Both are written.
- R5 (near-zero sensitivity, replaces the "interpolation changes by > 0.01 kW" trigger). Pre-registered brackets reported per stratum, W and direction as the median and p95 of the per-drive shift: (i) lower bracket: a run ends at the last same-sign sample (no interpolated tail); (ii) deadband: |P| below the current quantum x V (quantum from the observed current resolution of the drive) counts as zero (not a sign change); (iii) current offset: i_off from the drive record applied in both signs. Escalate if the p95 shift at a displayed W exceeds 5 % of the pooled p95 or the interval half-width. Interpolation (primary) stays as in M552.
- R6 (sign-change proxy). The audit's high / low sign-change drives are chosen by `drive_master.csv` column `n_sign_crossings`: the 3 largest and the 3 smallest (ties by file name) among eligible drives.
- R7 (language). "difference of percentiles is not the percentile of differences" is stated wherever the net and uninterrupted pooled values are shown side by side. Never "continuous", "steady" or "reversal penalty". Rules for AUD29-N02 are added to `language_gate.py`. Q5: payload carries the gap; the display shows only the share of drives whose M552 argmax window is uninterrupted. Q3: drive-level maximum over runs is kept; no per-length-class breakdown; the exposure sensitivity uses eligible run time.

# M552 blind-audit brief (claim and data path only)

Task: for the drives in `analyses/M552_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its file name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), reproduce from the raw CSV the highest and lowest net mean power over windows of 5, 10, 30, 60 and 120 s. Code the window logic yourself. Do NOT read `tools/power_duration.py`, `tools/energy_packets.py`, `analyses/M552_check*.json`, `duration_cache/`, `summary_arrays.json` or `analyses/M552_spec.md`. Only the pairing helpers may be shared: `import compute_drive_summary_v6 as D` (repo root on sys.path, PYTHONUTF8=1); `df, t = D._prep_bytes(csv_bytes)`; `I = D._series(df, t, 'I')` then keep `abs(I['v']) < 900`; `V = D._series(df, t, 'V', lo=200, hi=450)`; `e = D._asof(I.copy(), V, 'V', D.V_ALIGN_TOL).dropna(subset=['V'])`.

Definitions. Id = -e['v'] (discharge positive); P = Id * e['V'] / 1000 kW at each pair sample, time in seconds from `e['t']`. Power is LINEAR between consecutive pair samples (a duplicate timestamp is a zero-length interval that carries no time or energy; power may jump there). A GAP is a raw time step > 5 s between consecutive pair samples: it ends the supported segment, nothing is bridged or extrapolated, and no window may span a gap. A SEGMENT is a maximal chain of pair samples without a gap.
For a window length W (seconds) and a start s inside a segment with s >= segment start and s + W <= segment end, the window mean is M(s) = (1/W) * integral of P over [s, s + W] (exact integral of the piecewise-linear power). For each segment compute the EXACT continuous-start maximum and minimum of M(s) over all allowed s (note M is piecewise quadratic in s; do not restrict s to sample times or to a grid; your result must be exact to 1e-3 kW or better), and also the maximum and minimum over the 1 s start grid s = segment start + k (k = 0, 1, 2, ... while s + W <= segment end). Per drive and W: discharge value = max(0, largest M over all segments), charge value = max(0, -smallest M over all segments), for the exact search and for the grid; nSegEligible = number of segments at least W long; eligibleSeconds = the summed length of those segments. A drive with no segment at least W long reports zeros and nSegEligible 0.

Return one JSON file `M552_audit_result.json` in your scratchpad: for each master key and each W in 5, 10, 30, 60, 120: dis, chg, gridDis, gridChg, nSegEligible, eligibleSeconds. Report ambiguities you resolved instead of silently choosing. Stop after the sample drives.

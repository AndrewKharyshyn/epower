# M352 spec (rev 1): wording group B, ambient source transparency (F13.3, p21.5, p21.6)
Status: work in progress, Director string review pending. Additive keys inside the existing `ambientTable` block (generated by `tools/build_ambient_table.py`, an ingest stage; the new keys and their only consumer, the Ambient section of the Thermal tab, ship in this milestone). No estimate, no existing leaf value, no cohort assignment changes.

## 1. Facts (script-checked on `seasonal_drive_master.csv`, 489 drives)
- Source: every drive's ambient is `vehicle_sensor` (driver-recorded dashboard readout entered by hand), uncertainty class `vehicle_uncalibrated`; mixed-source 0; no substituted (weather/reanalysis) value.
- The ambient mean that sets the thermal cohort (`ambient_time_mean_c`, `seasonal_core.ambient_derived_fields`) is: trapezoidal over >= 3 timed readings (20 drives: warm 19, shoulder 1), the mean of the two readings (start, end) for 2 readings (400: warm 330, shoulder 68, cold 2), the single value for 1 reading (69: warm 38, shoulder 31). The table format string calls `m` a "time-weighted mean": true for 20 drives only.
- Other ambient products use different definitions: `batteryVsAmbient` / `belowAmbient` (start and end readings, pack-mean minus ambient at start and at peak), `auxLoadAmbient` (start reading; Spearman vs standstill draw), thermal cohort (the mean above).

## 3. Strings (old -> new)
- format: `m = time-weighted mean ambient` -> `m = ambient mean that sets the thermal class: trapezoidal over >= 3 timed readings, the mean of the two readings (start, end) for 2 readings, the single value for 1 reading (see meanKindByCohort)`.
- _provenance fragment: `driver-recorded vehicle readouts, source vehicle_sensor` -> `driver-recorded readings from the vehicle dashboard readout entered by hand (source label vehicle_sensor), interpolated between where interim readings exist`.
- Section intro: adds "All {recorded} of {n} ambient values are driver-recorded (uncalibrated); {substituted} are substituted. The mean that sets the thermal class is a trapezoidal mean for {t} drives, the mean of start and end readings for {e} and a single value for {s}; it is not a continuous time-weighted mean for most drives."
- Forbidden: "time-weighted mean ambient" for the table mean, "measured ambient", "sensor-measured outside temperature", "continuous ambient". Required: "driver-recorded", "uncalibrated", "endpoint-pair" (or "mean of start and end readings"), counts bound to the payload.

# M551 blind-audit brief (claim and data path only)

Task: for the drives in `analyses/M551_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its file name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), reproduce the energy-run (packet) table of each drive from the raw CSV. Code the run logic yourself. Do NOT read `tools/energy_packets.py`, `analyses/M551_check*.json`, `packet_cache/`, `summary_arrays.json` or `analyses/M551_spec.md`. Only the pairing helpers may be shared: `import compute_drive_summary_v6 as D` (repo root on sys.path, PYTHONUTF8=1); `df, t = D._prep_bytes(csv_bytes)`; `I = D._series(df, t, 'I')` then keep `abs(I['v']) < 900`; `V = D._series(df, t, 'V', lo=200, hi=450)`; `e = D._asof(I.copy(), V, 'V', D.V_ALIGN_TOL).dropna(subset=['V'])`.

Definitions. Id = -e['v'] (discharge positive); P = Id * e['V'] / 1000 kW per pair sample. Power is linear between consecutive pair samples; for each consecutive pair (p0, p1, raw step dt in seconds, step used d = min(max(dt, 0), 5)) the energy is split exactly like the master's ledger (directional, zero-crossing aware): if p0 * p1 < 0 the positive portion is d/3600 * p+^2 / (2 (|p0| + |p1|)) summed over the positive endpoints' squares, the negative portion likewise with the negative endpoint(s); otherwise the signed trapezoid d/3600 * (p0 + p1) / 2 is discharge when positive and charge (magnitude) when negative. A GAP is an interval with raw step dt > 5 s: its (capped, d = 5 s) energy is reported separately by direction (gapDischargeKwh, gapChargeKwh) and the gap ends the supported segment. A zero or negative raw step carries no energy; a strict sign change across it (p0 * p1 < 0) breaks a run. An IDLE interval (both endpoints exactly 0, not a gap) carries no energy and breaks a run.
A RUN is a maximal chain of same-sign directional portions inside one segment with no break (idle interval, duplicate-time sign change, gap) between its portions. A crossing interval ends the run of the sign it leaves and starts a run of the other sign at the crossing point (the first portion lasts |p0| / (|p0| + |p1|) of the step). Run energy in Wh = sum of its portions x 1000, duration in s = sum of the portion durations. A run is CENSORED at the start when its first portion is the first portion of its segment with no break marker before it inside the segment, and censored at the end when its last portion is the last portion of its segment with no break marker after it. Mid-segment breaks (idle, duplicate-time) are observed ends and do not censor.

Return one JSON file `M551_audit_result.json` in your scratchpad, one entry per master key: nPairs, nGaps, nIdle, nRunsAll, nRunsCensored (start or end), nRunsComplete, sumDischargeRunsKwh, sumChargeRunsKwh, gapDischargeKwh, gapChargeKwh, completeBelow1WhCount, completeBelow1WhEnergyWh, medianCompleteWh (null if none), maxRunWh. Report ambiguities you resolved instead of silently choosing. Stop after the sample drives.

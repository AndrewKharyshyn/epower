# M663 spec (Rev 1): UI-05 seventh slice, drives-per-day calendar heatmap

Presentation only, written before the build. The "Sessions (grouped by phase)" section shows hand-typed phase and per-day ledger bars. M663 adds, above them, a calendar heatmap of drives per calendar day: one square per day from the first to the last logged day, weeks as columns (Monday first), darker = more drives that day, grey = no drive logged. Source: the per-drive dates S.ambientTable.rows[].d (all drives of the master; not the hand-typed ledger, which the caption says). Pure model driveCalendarModel (invalid dates ignored, never counted), the day-by-day list sits behind ChartWithTable. The phase ledgers, the ledger audit and the extend_session_ledgers stage are untouched; no payload, method or figure change. Test: test_drive_calendar.js (known-answer model test on a Sunday/Monday boundary and invalid inputs; render check: each logged day carries its count, squares sum to the drive count, table rows equal logged days).

# M662 spec (Rev 1): UI-05 sixth slice, stop-go drive-type strips

Presentation only, written before the build. The stop-go panel prints, per drive type, median cycles per drive and median engine starts per 10 min of stop-go as tiles. M662 adds two dot strips (IntervalForest) with the median and the interquartile range of drives (p25 to p75), bound to S.crawlStopGo.byDriveType[k].cyclesPerDrive / startsPer10minStopGo (cohort views use the cohort block as the tiles do), n drives in each label; a type flagged in smallDenominatorDriveTypes carries "(high-variance)" in its label. The interval is an interquartile range of drives, NOT a 95% interval: IntervalForest gains an optional prop intervalName (default "95% interval", so all earlier charts are byte-identical) and the footer names the range. A type without a median is text, never zero. The tiles stay behind ChartWithTable unchanged. No payload, method or figure change; no inference is added. Test: test_stopgo_forest.js (4 types x 2 quantities equal the payload at the printed precision, IQR named, tiles behind toggle).

# M661 spec (Rev 1): UI-05 fifth slice, fuel by speed state forest

Presentation only, written before the build. The Fuel-tab panel "Fuel by speed state" draws stacked point shares and prints the stationary share with its 95% day-clustered interval only in a table. M661 adds a forest of the stationary share (%, 2 dp) per group (all, trip-distance bands, drive types, cohorts; the cohort rows in the cohort views), bound to S.fuelStates.groups[k].stationaryShare (est, ci95) with trips in the row label. A group without an interval is an open point; a group without an estimate is text, never zero. The table stays behind ChartWithTable unchanged, the stacked bars stay. Caption: temporal state of the logged (app-calculated) fuel rate, not an allocation of fuel to a source. No payload, method or figure change. Test: test_fuelstates_forest.js (13 groups, values and intervals equal the payload at 2 dp, table behind toggle).

# M732 spec Rev 2: extractor of P1 (start-temperature accuracy of the state-model chain on winter drives)

Status: Rev 2 after the Director review of Rev 1 (decision "revise"; record `analyses/M732_director_review_rev1.json`; no Andrii sign-off required). Written BEFORE any code and before any winter observation is read. Rev 2 changes are in section 6 and override sections 2-4 where they differ. Author: main session. P1 was split off from M728 (Director, M728 Rev 2) because it needs the production park-model pair builder, the M709 unlogged-use flag, the diurnal convention and the free-run rules vendored and verified. This milestone must be frozen before the 2027-02-11 look, else P1 is "not evaluable" there.

## 1. The frozen prediction (not changed)
`analyses/M717_winter_predictions.json` P1: "free-run MAE of the simulated start temperature <= 3 C and |bias| <= 2 C; park model: held-out bias within +-1 C at gaps >= 12 h and within +-0.5 C around the 10 and 15 C thresholds on winter restart pairs". Frozen parameters: `params.park` (tau 9.105 h, offset 0.469 C), `params.driveHeating` (alpha 0.013093, tau_d 0.986873, c0 23.87691, c1 0.220106, EaR 17.582 kJ/mol), `params.diurnalAmbient` (autumn amp 5.8 / hpk 15.543; winter amplitude = autumn x 0.7, the `amp_w_scale` of `scenarioDefaults`). Scored before any refit. Support: 10 drives (pairs) on 5 days per part. All temperatures model-derived; the logged start temperature is the mean of the pack-temperature probes at the first sample, not a measurement of the cell.

## 2. Two parts (two cells, never merged)
**Part A: free-run chain.** A segment is a maximal run of consecutive logged drives with gap <= GAP_MAX_H (the production `restart_census.GAP_MAX_H`) and no M709 flag (`mp_soc`, `mp_coolHot`, `mp_coolUp`, odometer step, overlap, duplicate) on any of its joins. The first drive of a segment is the anchor: its simulated start equals its logged start and it is not scored. For every later drive k: T_end(k-1) is simulated from the simulated start of k-1 with the frozen drive path (production `exposure_state.drive_path`: logged current-squared slices, slice dt, driver-read drive ambient, frozen heating), then the simulated start of k = `park_model.park_T`(T_end(k-1), gap, clock, A_end(k-1), slope, amp_w, hpk, tau, offset) with the frozen park parameters and the winter diurnal convention; errors are e_k = simulated minus logged start of k (propagated, never reset after the anchor). Statistic: MAE = mean |e|, bias = mean e, over scored drives; day-clustered percentile bootstrap (default_rng(42), 4000 draws, days ascending) for both. Reading: "within" if MAE upper bound <= 3 and |bias| bounds inside +-2; "outside" if MAE lower bound > 3 or the bias interval lies wholly outside +-2; else "inconclusive".
**Part B: park model on winter restart pairs.** Pairs = `restart_census.build_pairs` of the scoring window, eligible and NOT flagged (M709 unlogged-use flag). Prediction from the OBSERVED previous end temperature (no chain), frozen parameters, no refit; bias = predicted minus logged start. Two tolerance cells: gaps >= 12 h within +-1 C; pairs whose logged start lies within +-2 C of 10 C or of 15 C within +-0.5 C (the "thresholds" cell). Each: mean bias with day-clustered interval; "within" if the interval lies inside the tolerance, "outside" if wholly outside, else "inconclusive".

## 6. Rev 2 (Director rulings on Rev 1)
R1 **Free-run = no re-anchoring** (the prototype `exposure_scenarios_2026-11-16/thermal_model.py free_run` that set the 3 C threshold uses one initial temperature and re-anchors only when the state is non-finite). The anchor is the first post-freeze drive (logged start). The chain is propagated THROUGH `mp_*` flagged joins and odometer-step joins; it re-anchors only at a non-finite state, an overlap or a missing ambient; re-anchors are counted and the anchor drives are not scored. The flag-segmented chain of section 2 (Rev 1) is kept as a SENSITIVITY, never the primary.
R2 **Part B windows** follow the M709 E4 convention: +-3 C on the logged start, two separate cells, 10 C [7, 13] and 15 C [12, 18], not pooled; +-2 C and selection on the predicted value are sensitivities.
R3 **Rule** (all cells): "within" = the day-clustered interval lies inside the tolerance; "outside" = the POINT estimate lies outside it (M712 section 9 falsifier), interval reported beside; otherwise "inconclusive". P1 is "within" only if every cell is within; any cell not evaluable makes P1 "not evaluable".
R4 **Decisions.** D1 accept: winter amplitude 0.7 x 5.8 for Dec-Feb only (engine `wint`), 5.8 otherwise, hpk 15.543, amplitude taken from the previous drive; scale 1.0 is a sensitivity. D2 accept with an `ambientByDrive` snapshot sha256 in the cell. D3 accept; `mp_*` is the flag, odometer step / overlap / duplicate are exclusions (wording fixed). D4 accept for scoring, but such drives are still propagated. D5 primary window = Dec-Feb drives; post-freeze November is reported beside.
R5 **C-P1b** is: (i) the extractor equals the vendored functions re-run with UNROUNDED amp / hpk to 1e-9; (ii) against the stored M709 summaries at stored precision: modelPairs 596 exact, biasNear15C -0.269 +-5e-4, mae_Tend 0.74 and bias -0.037 at stored precision; (iii) the effect of the rounded stored parameters is reported. The prototype free-run is descriptive only, not a target.
R6 **Sensitivity** added: a 7-day block bootstrap (the chain carries error across days, so the day bootstrap may understate variance).
R7 **Disclosure** carried in every cell: restart ambient is a heat-soaked vehicle sensor reading (an input); winter amplitude x0.7 is an assumption; the parameters were fitted on May-Nov, so winter is out-of-time, not a clean hold-out. Language: "model-derived, propagated start-temperature error"; the logged start is the pack-probe mean at the first sample, never "measured"; "within the frozen tolerance", never "validated" or "accurate"; inconclusive or not evaluable is not "holds"; cold outputs stay NOT SUPPORTED.

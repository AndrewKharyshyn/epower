# M659 spec (Rev 1): UI-05 third slice, heat-soak carryover forest

Presentation only, pre-registered before the build. Scope: the Thermal-tab panel "Heat-Soak Carryover" prints the retained-heat result per parking-gap bin as a monospace listing. M659 adds a forest of the median retained share (100 x medRetainedFrac) per gap bin, bound to S.heatSoakCarryover.gapBins, with n (pairs, pairs with ambient) in each row label. The listing stays behind ChartWithTable unchanged. The payload prints no interval for these medians, so none is drawn (open dot) and none is invented. A bin without a ratio is shown as text, never as zero. No new figure, no payload change, no method change; the caveat that the ambient is hand-entered and long-gap bins sit near or below zero by construction is printed in the chart caption. Test: test_heatsoak_forest.js (value equals payload, n in label, table behind toggle). No audit tier beyond the jsdom test: the chart plots existing payload values only.

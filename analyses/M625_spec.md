## 2. Change (pre-registered)
One helper `tools/scope_label.py` with two pure functions, used by every site above:
`month_span(dates)` returns the calendar span of the analysed drives' dates: 'May-November 2026' when first and last month fall in one calendar year, 'May 2026-May 2027' across years (full English month names, hyphen); `ambient_span(values)` returns 'ambient -1 to 38 C' (min and max of the finite start readings, integers when all values are whole numbers, else one decimal; a negative number is written with the ASCII minus). The population passed in is each block's own analysed set: for the time-to-threshold ledger, the m435 estimators and the strata the coolant cold-start drives of the cohort the block reports (all), their dates and their driver-recorded start ambient (`summary_config.json ambientByDrive[file][0]`, list entries only, as `auxLoadAmbient`); for the four capacity / dependence / scenario / serial blocks the canonical-clean master rows (`ens_outlier_v2` false) with a date; if a block's own eligible rows are exposed by its code, those are used instead and the choice is stated in its `limits`. The cold-cohort sentence in `thermal_support_ledger.py` takes its ambient range from the cold cohort's own drives (`seasonalCharts` Cold coverage `ambient_range_c` is the existing source) and keeps its 'winter stays unobserved' clause only while the cold cohort's date range does not cover December to February (the clause is generated from the dates, not typed).
No other string or number changes. Payload keys are never renamed. Consumers: the semantic gate reads `requiredSentences.R4` from the payload (equality of the rendered sentence with the payload), so the rendered text follows automatically; the jsx displays `timeToThreshold.label`; both are verified in the isolation diff.

## 3. Known-answer tests (new, under `tests/synthetic/`)
`month_span`: ['2026-05-11', '2026-10-31'] -> 'May-October 2026'; ['2026-05-11', '2026-11-09'] -> 'May-November 2026'; ['2026-05-11', '2027-05-10'] -> 'May 2026-May 2027'; one month -> 'May 2026'; empty -> None (the caller then states 'scope not available', never a literal). `ambient_span`: [3, 38] -> 'ambient 3 to 38 C'; [-1.0, 38.0] -> 'ambient -1 to 38 C'; [-0.5, 12.25] -> 'ambient -0.5 to 12.3 C' (round half even is NOT used: decimal formatting rule fixed in the test); NaN and None ignored; all missing -> None. A static test greps the seven producer files and fails on any remaining literal month list or typed ambient range ('May-October', 'ambient 3-38', '3-5 C').

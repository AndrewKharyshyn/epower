# M550 blind-audit brief (claim and data path only)

Task: reproduce, from the raw drive CSVs alone, for the drives in `analyses/M550_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), the timestamp of the drive's peak charge POWER sample, the pack temperature T1 at that moment, its signed age and its tier. Do not read `tools/power_peak_temp.py`, `analyses/M550_check*.json`, `powerpeak_cache/`, `summary_arrays.json` or `analyses/M550_spec.md`.

Definitions. Use the repo helpers for parsing so the time base is identical: `import compute_drive_summary_v6 as D; df, t = D._prep_bytes(csv_bytes)`; series with `D._series(df, t, col, lo, hi)`; alignment with `D._asof(base, other, name, tol)`. Channels (column names after `_prep_bytes`): `I` (pack current, charge-positive; keep |I| < 900), `V` (pack voltage, 200..450), `T1` (battery temperature sensor 1, -40..90). Current samples are the base; the voltage is aligned to each current sample as the nearest voltage sample within `D.V_ALIGN_TOL` (rows without a voltage are dropped). Id = -I (discharge positive); P = Id * V / 1000 kW (charge negative). The peak charge power sample is the FIRST row (in time order) at which P is minimal. T1 at that moment = the nearest native T1 sample (no interpolation) by absolute time distance; signed age = (T1 sample time - peak sample time) in seconds. Tiers by |age|: cotimed <= 1 s, nearby <= 3 s, late <= 10 s, none beyond 10 s or no T1 sample. Also report the drive's minimum Id (peak charge current, 1 decimal) and the minimum P (1 decimal).

Return one JSON file `M550_audit_result.json` in your scratchpad: for each master key in the sample: tPeakKw (ISO string as pandas prints it), minP, minId, T1AtPeakKw (null if the tier is none or late: give `T1Nearest` and `ageS` always), ageS (signed), tier, and nTiesAtMinP (rows with P exactly equal to the minimum). Report ambiguities you resolved instead of silently choosing. Stop condition: the sample drives only.

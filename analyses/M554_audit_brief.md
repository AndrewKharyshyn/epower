# M554 blind-audit brief (claim and data path only)

Task: for the drives in `analyses/M554_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its file name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), compute from the raw CSV the union-clock energy defined below. Code everything yourself. Do NOT read `tools/common_support.py`, `tools/integration_scenarios.py`, `analyses/M554_check*.json`, `bridge_cache/`, `summary_arrays.json` or `analyses/M554_spec.md`. Shared: only the column map and the filters below (no pairing helper): columns `time` (parse with pandas; mixed formats), `[BMS] HV Battery Current (A)` (I), `[BMS] HV Battery voltage (V)` (V). Keep non-missing samples; I with abs(I) < 900; V with 200 <= V <= 450; sort by time; if a channel has duplicate timestamps keep the LAST sample of the duplicate group. Time in seconds from the earlier of the two channels' first valid sample.

Definition (union clock). Id = -I (discharge positive). Each channel is linear between its consecutive valid samples, and a channel is NEVER interpolated across a gap of its own longer than Gmax seconds (consecutive valid samples more than Gmax apart). The union grid is the sorted unique times of both channels' valid samples. A union step [t_k, t_k+1] is SUPPORTED iff (a) t_k+1 - t_k <= 5 s, and (b) the step lies inside a consecutive-sample interval of the current channel with length <= Gmax AND inside one of the voltage channel with length <= Gmax. Nothing is bridged. Inside a supported step Id and V are linear, so P = Id V / 1000 (kW) is quadratic; the step energy is the EXACT integral (kWh = integral of P dt / 3600). Because V > 0, the sign of P is the sign of Id: if Id changes sign inside the step, split at its single root and integrate each side exactly. Discharge energy = integral over the parts with Id > 0; charge energy = integral over the parts with Id < 0, reported as a positive number.
Return, per master key and for Gmax in 5 (main) and 3 (sensitivity): uDis, uChg (kWh), uSupportSeconds (sum of supported step lengths), nSupportedSteps. Return one JSON file `M554_audit_result.json` in your scratchpad. Report ambiguities you resolved instead of silently choosing. Stop after the sample drives.

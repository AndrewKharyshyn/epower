Status: Rev 0, written BEFORE any M623 result exists (2026-11-12; master 665 drives, MD5 77bbe275f8c22eaf62d8636867764af3; main at 385ada7). Needs a Director review (`research-director`) before any code; blind audit (`analytical-auditor`) of the implementation and a Director decision after it (CLAUDE.md: method change / displayed figure change). Audit sources: self-audit finding A-1 (aux-load bins) and the external audit (warm-up bin), both re-verified on disk by the author's reading of the code below; audit figures are leads, every number in the result is script-written.
Wording: standstill draw is a climate-load PROXY (no HVAC state channel), never measured HVAC power; coolant and oil temperatures are logged/app-calculated; descriptive, single vehicle, no causality.

## 1. Defects (read from the code)
D1 (`compute_summary_arrays._aux_load_ambient`, `edges = [10, 15, 20, 25, 30, 40]`, `np.digitize(x, edges[1:-1])`): `digitize` against the inner edges [15, 20, 25, 30] returns bin 0 for EVERY value below 15 C and bin 4 for every value from 30 C up, but the labels say '10-15' and '30-40'. All cold-start drives (ambient below 10 C; lowest so far about -1 C) are reported in the '10-15 C' bin. The interpretation string and `xtrail_summary.jsx:8439` state 'rises monotonically above ~15 C' and the code comment says 'No sub-15C data exists'; both are stale.
D2 (`_thermal_warmup_lag`, `_TWL_TIME_BINS = [0, 30, 60, 120, 180, 240, 300, 420, 600, 900]`, `np.digitize(tsec, _TWL_TIME_BINS[1:-1])`): the last bin is labelled '600-900' but holds every sample from 600 s to the end of the drive (no upper bound), so its median mixes arbitrary elapsed times.
Same bug class: a closed-looking label on an open-ended bin.

## 2. Changes (pre-registered, no tuning after the result)
D1. Edges `[-inf, 5, 10, 15, 20, 25, 30, +inf]`, intervals right-open `[a, b)` as the present `digitize` already treats interior values. Labels from the edges: '<5', '5-10', '10-15', '15-20', '20-25', '25-30', '>=30' (the old '30-40' label is replaced by '>=30'; the corpus maximum start ambient is below 40 C, stated from the data in the payload). Support rule unchanged (a bin is reported only with n >= 5 drives); each bin additionally reports `nDays` (calendar days). Medians and p25/p75 unchanged in definition. The 'monotonic' sentence is DERIVED: it is emitted only when the medians of the reported bins at and above 15 C are strictly increasing, and the below-15 C behaviour is described from the same bins (two-sided climate load: a heating-related rise at low ambient and a cooling-related rise at high ambient are both possible readings, neither is identified); no literal numbers in the jsx sentence (bind to `byAmbientBin`). The stale comment, the 'interpretation' string and the 'thinly observed' sentence are regenerated from the bins and n.
D2. Samples with `tsec >= 900` are excluded from the warm-up curves (mask before `digitize`); labels unchanged ('600-900' now correct); each bin reports `nDrives` and `nDays` contributing (new additive leaves; chart consumption of n/IQR is W1-03, not this milestone).

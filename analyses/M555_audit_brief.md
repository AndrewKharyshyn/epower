# M555 blind-audit brief (claim and data path only)

Task: for the files in `analyses/M555_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its file name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), compute the quantities below from the raw CSV. Code everything yourself. Do NOT read `tools/cell_observability.py`, `analyses/M555_check*.json`, `cell_cache/`, `summary_arrays.json` or `analyses/M555_spec.md`. Shared: only column names. Columns: `time` (parse with pandas `format="mixed"`; time in seconds from the first valid pack sample), the pack namespace `[BMS] HV Battery voltage (V)` (keep only values 200..450 V), `[BMS] Max Cell Voltage (V)`, `[BMS] Min Cell Voltage (V)`, the logged `G01 Cell Voltage  (V)` channel (two spaces before `(V)`), and the per-cell channels whose names contain `Battery Cell #`. For every channel keep non-missing numeric values, sort by time, and if timestamps repeat keep the LAST sample of the group.

Per file return, for Max, Min, G01 (when present and non-empty) and for the per-cell channels aggregated only as a COUNT of channels in each coverage class (see below):
- `n` (samples after dedupe), `nNonMissing` (non-missing values before dedupe), `rateRatio` = n / number of pack samples.
- `coverage` = share of pack samples that have a channel sample within +-1.5 s.
- `exactCoTimed` = share of channel samples whose timestamp equals a pack sample timestamp exactly.
- `offsetMedian`, `offsetP95` of the absolute offset from each channel sample to the nearest pack sample (seconds).
- Age: for each pack sample, the time since the last channel sample at or before it (not since the value changed); samples with no earlier channel sample are censored. Return `ageCensoredShare`, `ageMedian`, `ageP95` (over uncensored), `ageOver3sShare` (share of uncensored with age > 3 s).
- Coverage class counts for the per-cell channels: complete (coverage >= 0.95), partial (0.50 to < 0.95), sparse (< 0.50); also the number of per-cell channels with samples.
Max / Min consistency (files with both): resolution = max over the two channels of the largest 10^-d, d = the largest number of decimals among that channel's logged values (e.g. values with up to 3 decimals give 0.001). POLLING pairing: each Max sample takes the first Min sample at or after it and before the next Max sample, if that Min is at most 1.5 s later; one-to-one. Return `pollPairs`, `pollViolations` (Max < Min - resolution), `unmatchedMax`, `unmatchedMin` (Min samples never used). NEAREST pairing: each Max sample takes the nearest Min sample within tau (reuse allowed) for tau in 0.25, 0.5, 1.5: return pairs and violations.
Return one JSON file `M555_audit_result.json` in your scratchpad keyed by master key. Report ambiguities you resolved instead of silently choosing. Stop after the sample files.

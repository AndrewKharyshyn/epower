# M553 blind-audit brief (claim and data path only)

Task: for the drives in `analyses/M553_audit_sample.json` (`files`, master keys; the raw file in `raw/` matches a master key by the digits of its file name, e.g. key `20260511_185709.csv` = `raw/2026-05-11 18-57-09.csv`), reproduce from the raw CSV the net-charge and terminal-energy excursions below. Code the logic yourself. Do NOT read `tools/window_use.py`, `tools/power_duration.py`, `tools/energy_packets.py`, `analyses/M553_check*.json`, `window_cache/`, `summary_arrays.json` or `analyses/M553_spec.md`. Only the pairing helpers may be shared: `import compute_drive_summary_v6 as D` (repo root on sys.path, PYTHONUTF8=1); `df, t = D._prep_bytes(csv_bytes)`; `I = D._series(df, t, 'I')` then keep `abs(I['v']) < 900`; `V = D._series(df, t, 'V', lo=200, hi=450)`; `e = D._asof(I.copy(), V, 'V', D.V_ALIGN_TOL).dropna(subset=['V'])`.

Definitions. Id = -e['v'] (discharge positive, A); V = e['V']; P = Id * V / 1000 kW at each pair sample; time in seconds from `e['t']`. The signal (Id or P) is LINEAR between consecutive pair samples (a duplicate timestamp is a zero-length interval carrying nothing). A GAP is a raw time step > 5 s between consecutive pair samples: it ends the supported segment; nothing is bridged. A SEGMENT is a maximal chain of pair samples without a gap.
Per segment, the cumulative trace Q(t) = integral from the segment start of the signal dt / 3600 (Id gives Ah, P gives kWh; exact integral of the piecewise-linear signal, which is piecewise quadratic, so the extremum of Q inside an interval where the signal changes sign lies at the zero crossing, not necessarily at a sample). The segment EXCURSION = max Q - min Q over the whole segment (exact, including interior zero-crossing vertices). Per drive: `upper` = sum of the segment excursions, `lower` = the largest single segment excursion, `netSegSum` = sum over segments of Q at the segment end, `nSeg`, `gapShare` = (sum of raw steps > 5 s) / (last pair time - first pair time). Do this for Id (Ah) and for P (kWh). Also return for each drive the offset variant `upperAhOff` and `upperKwhOff`, computed with Id replaced by Id - off where `off` is the per-drive constant I_offset_A_applied from `drive_master.csv` (NaN -> 0).
Return one JSON file `M553_audit_result.json` in your scratchpad: for each master key: ah{upper,lower,netSegSum,nSeg,gapShare}, kwh{upper,lower,netSegSum,nSeg,gapShare}, upperAhOff, upperKwhOff. Report ambiguities you resolved instead of silently choosing. Stop after the sample drives.

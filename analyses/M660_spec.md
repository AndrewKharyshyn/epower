# M660 spec (Rev 1): UI-05 fourth slice, warm-up fuel trajectory interval chart

Presentation only, written before the build. The Fuel-tab panel "Warm-up fuel trajectory" already draws the cumulative-litres curves; its second table (moving-sample L/100 km in 0.5 km intervals after the first engine start, per initial-coolant band, all-data view) is only text. M660 adds a BandSeries of those values, one series per band, x = start of the interval, bound to S.fuelWarmup.groups["all|<band>"].intervalConsumption (est, ci95, n in the table). Intervals the payload prints without a CI are open points (never invented); a missing ratio is skipped, never zeroed. The tables stay behind ChartWithTable unchanged. Caption states: pointwise day-clustered intervals, logged/app-calculated fuel, associations only. No payload, method or figure change. Test: test_fuelinterval_chart.js (30 points equal the payload at 1 dp, intervals match, table behind toggle).

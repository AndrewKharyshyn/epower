# M665 spec (Rev 1): UI-05 ninth slice, heat-soak held-out observed-versus-predicted by gap bin

Presentation only, written before the build. The held-out fit-quality block of the heat-soak panel (pack, coolant, oil) prints the median observed and model-predicted retained fraction per parking-gap bin only as a sentence. M665 draws it as three small charts (one per fit; observed solid, predicted dashed) over the ordinal gap bins, bound to S.heatSoakCarryover.soakFitQuality.bins and S.interDriveCarryover.thermalDecay.{coolant,oil}.fitQuality.bins; bins with no held-out pair are skipped. The payload prints no interval for these medians, so none is drawn (open points). Deviation from the backlog wording ("scatter on a log gap axis with held-out residuals"): no pair-level data are in the payload and none is created, so the axis is the ordinal bin (the last bin has no upper edge, so no log midpoint is invented), and the per-bin held-out pair and day counts sit in a table behind ChartWithTable, which replaces nothing: the original sentence stays. The caption says the last bins hold few pairs and a large difference there is not a pack property; tau stays a model-derived summary. No payload, method or figure change. Test: test_soakheldout_chart.js (3 fits, every bin x 2 values equal the payload at 2 dp, table rows equal bins, no interval).
